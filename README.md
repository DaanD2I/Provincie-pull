# Provincie-pull

Deze code wordt gebruikt om een lijst van alle postcodes bijbehorende gemeente en provincie te verzamelen. Dit wordt uitgevoerd op basis van de [pgeocode library](https://pypi.org/project/pgeocode/). Daarnaast is er gesplit in NL en BE. Mogelijkheden voor andere is landen, raadpleeg daarvoor de [pgeocode library](https://pypi.org/project/pgeocode/).
